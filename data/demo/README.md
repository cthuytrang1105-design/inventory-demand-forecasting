# DỮ LIỆU MÔ PHỎNG

`sales.csv` sinh bằng `python -m src.demo_data`, seed 42, 480 ngày, 3 cửa hàng và 3 nhóm hàng.
Các tên nhóm mượn từ ngữ cảnh bán lẻ; giá trị sales, lịch khuyến mãi đều mô phỏng.
Nguồn/đơn vị được ghi ở `sales.metadata.json` và đưa vào artefact huấn luyện.
Không có dữ liệu tồn kho thực. Không dùng kết quả này như kết quả thực nghiệm Kaggle.
